# CLI

Install and use the Opencode SEO Tools CLI to run SEO audits from your terminal.

## Installation

```bash
npm install -g opencode-seo-tools
```

## Usage

```bash
opencode-seo audit <url>
```

## Options

- `--include-sitemap` - Include sitemap in the audit
- `--max-depth` - Maximum depth to crawl
- `--max-pages` - Maximum number of pages to crawl
