# OpenCode Tool

FixSEO can be used as an OpenCode tool, allowing AI agents to scan websites for SEO issues.

## Installation

```bash
npx fixseo opencode
```

This installs the OpenCode tool in `.opencode/tools/`.

## Usage

After installing, tell your agent to check SEO for a URL. Copy this prompt:

```
Run a FixSEO scan on https://example.com and show me the results.
```
