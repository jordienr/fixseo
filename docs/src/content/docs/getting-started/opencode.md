# Opencode Tool

Use Opencode as an AI coding assistant that can help with SEO tasks.

## Installation

```bash
npm install -g opencode-ai
```

## Usage

Run Opencode and ask it to perform SEO audits or fix SEO issues in your code.

## Example Prompts

- "Run an SEO audit on my website"
- "Fix the meta tags on my landing page"
- "Check if my site has accessibility issues"
